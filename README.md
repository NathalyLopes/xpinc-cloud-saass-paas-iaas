# ☁️ Tipos de Serviços em Nuvem e Responsabilidade Compartilhada

Os três principais modelos de serviços em nuvem: **IaaS, PaaS e SaaS**

1. IaaS – Infrastructure as a Service
Infraestrutura como Serviço
    
    Cria uma infraestrutura de TI de pagamento conforme o uso alugando servidores, máquinas virtuais, armazenamento, redes e sistemas operacionais de um provedor de nuvem.

- O provedor oferece: servidores, redes, armazenamento e virtualização.
- O cliente gerencia: sistema operacional, aplicativos, dados e segurança.
- Exemplos: Microsoft Azure (VMs), Amazon EC2, Google Compute Engine.
- Mais flexível, mas exige maior controle técnico do usuário.

2. PaaS – Platform as a Service
Plataforma como Serviço
    
    Fornece um ambiente para a criação, o teste e a implantação de aplicativos se software, sem focar no gerenciamento da infraestrutura subjacente.

- O provedor oferece: infraestrutura + sistema operacional + banco de dados + ambiente de execução.
- O cliente gerencia: apenas os aplicativos e dados.
- Exemplos: Azure App Services, Google App Engine, Heroku.
- Ideal para desenvolvedores: menos gestão de infraestrutura, mais foco no código.

3. SaaS – Software as a Service
Software como Serviço

    
    Os usuários se conectam e usam aplicativos com base em nuvem pela Internet, por exemplo: Microsoft Office 365, email, calendários.

- O provedor oferece e gerencia tudo: software, infraestrutura, segurança e atualizações.
- O cliente apenas utiliza o software via navegador ou app.
- Exemplos: Gmail, Microsoft 365, Dropbox, Salesforce.
- Nenhuma instalação ou manutenção local é necessária.

# 🔐 O que é o Modelo de Responsabilidade Compartilhada?
O modelo de responsabilidade compartilhada é um conceito fundamental da computação em nuvem, que define quem é responsável por cada parte do ambiente de tecnologia: o provedor da nuvem como Azure, AWS, Google Cloud ou o cliente/usuário ou seja, sua empresa ou equipe técnica.

# 🧩 Exemplos práticos

- **IaaS** 
O provedor entrega servidores virtuais e rede.
Você cuida do sistema operacional, atualizações, antivírus, apps, dados e permissões.
**Ex: máquinas virtuais no Azure ou AWS**

- **PaaS** 
O provedor gerencia toda a infraestrutura e a plataforma de execução.
Você só cuida do seu código e dos dados.
**Ex: Azure App Service, Google App Engine**

- **SaaS** 
O provedor gerencia tudo.
Você apenas usa o serviço e gerencia os seus dados (e acessos).
**Ex: Office 365 e Gmail**
